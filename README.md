# RepForge

Premium, local-first calisthenics tracker PWA for Pullups, Pushups, Dips and Squats.

## Cloud providers
- Local only
- Firebase / Firestore
- Google Drive

The provider is selected in **More → Account & sync**. The core data model is provider-independent.

## Deployment
See `SETUP-SYNC.md` for complete Firebase, Google Drive and GitHub Pages deployment steps.

## Privacy
RepForge does not require a backend to function. Cloud sync is opt-in. Full JSON Backup/Restore is always available.
